# FANUC BIW Spot Welding Using Industrial Robot

## Project Overview
This project demonstrates an automated **Body-in-White (BIW) spot-welding process** using a FANUC industrial robot. The robot uses a servo spot-welding gun to perform welding operations at predefined positions on automotive sheet-metal components.

The project focuses on industrial robot programming, position teaching, motion control, spot-welding sequences, and manufacturing automation.

## Project Details
- **Project Title:** FANUC BIW Spot Welding Automation
- **Robot:** FANUC Industrial Robot
- **Controller:** FANUC R-30iB
- **Programming Interface:** FANUC Teach Pendant
- **End Effector:** Servo Spot-Welding Gun
- **Application:** Automotive Body-in-White (BIW) Assembly
- **Welding Points:** Two demonstration points

## Objectives
- Understand FANUC industrial robot programming.
- Demonstrate automated automotive spot welding.
- Learn robot position teaching using the Teach Pendant.
- Develop a basic welding sequence.
- Understand industrial automation and robot safety.

## Working Process
1. Start the robot program.
2. Move the robot to the safe approach position.
3. Move to the first welding point.
4. Position the servo welding gun.
5. Execute the first spot-welding operation.
6. Move to the second welding point.
7. Execute the second spot-welding operation.
8. Return the robot to its home position.

## Expected Results
The project demonstrates a two-point automotive BIW spot-welding sequence using a FANUC robot. It highlights the benefits of industrial automation, including:
- Improved welding consistency.
- Accurate robot positioning.
- Reduced manual effort.
- Increased manufacturing productivity.
- Better repeatability in automotive assembly.

## Safety Notice
This is an educational project and demonstration template. Robot positions, welding schedules, servo-gun configuration, I/O signals, and safety settings must be verified by qualified personnel before operation. Do not execute unverified programs on a physical robot.
